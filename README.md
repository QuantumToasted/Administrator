# Administrator

Discord server moderation/administration bot with TF2 influences.


### Public Bot Privacy Policy
Administrator collects and stores certain Discord PII (Personally identifiable information) through normal course of use as a public bot.
The following points detail what data is collected and for what purposes:

- User IDs
  - Used to identify records (tags, reminders, punishments, etc.) associated with a user
- Channel IDs
  - Used to identify records (reminders, bot configured channels, etc.) associated with a channel
- Guild (server) IDs
  - User to identify records (pubishments, per-guild settings, etc.) associated with a guild
- Usernames
  - Used solely for a "snapshot" of a user involved in a punishment for moderator records (as a reminder of the user's name at the time they were punished)

The above information is necessary for the bot to function correctly.

If you have any questions or concerns about the data above that is stored or wish to request its anonymization or removal, you can contact `@quantumtoasted` on Discord and best efforts will be made to accomodate your request.
